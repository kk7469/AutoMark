# AutoMark - 魔兽世界自动标记插件

## 功能介绍

AutoMark 是一个为魔兽世界 12.0.5 版本设计的自动标记插件，它能够帮助玩家快速标记队伍中的坦克和治疗职业。

### 主要功能

✅ **自动标记** - 进入副本后自动根据队伍职责标记队友  
✅ **一键标记** - 快捷键一次性标记所有队友  
✅ **自定义标记** - 可以修改每个职责（坦克、治疗、DPS）的标记  
✅ **设置界面** - 通过 `/mak` 命令打开图形化设置界面  
✅ **自动检测** - 根据游戏内部职业和天赋自动检测队友职责  

## 安装方法

1. 将 AutoMark 文件夹放入你的魔兽世界插件目录
   - Windows: `World of Warcraft\_retail_\Interface\AddOns\`
   - Mac: `World of Warcraft/_retail_/Interface/AddOns/`

2. 重启魔兽世界或使用 `/reload` 命令重新加载UI

3. 在游戏中使用 `/mak` 命令打开设置界面

## 命令说明

| 命令 | 说明 |
|------|------|
| `/mak` 或 `/mak set` | 打开设置界面 |
| `/mak auto` | 切换自动标记功能 |
| `/mak quick` | 一键标记所有队友 |
| `/mak clear` | 清除所有标记 |
| `/mak enable` | 启用插件 |
| `/mak disable` | 禁用插件 |
| `/mak config` | 显示当前配置 |

## 设置界面

### 基本设置
- **启用插件** - 启用/禁用整个插件
- **启用自动标记** - 启用/禁用进副本时的自动标记功能

## 工作原理

1. **进副本检测** - 当进入副本或加入队伍时，插件会自动检测
2. **职责识别** - 根据游戏内部的 `UnitGroupRolesAssigned()` 函数识别每个队友的职责
3. **自动标记** - 根据职责自动为队友应用相应的标记
4. **实时更新** - 每2秒检查一次，新加入的队友会自动被标记
5. **数据保存** - 所有配置自动保存到角色配置

## 常见问题

### Q: 插件不工作怎么办？
A: 请确保：
1. 已在设置界面启用插件
2. 已在设置界面启用自动标记
3. 已进入有效的队伍或副本
4. 使用 `/mak config` 查看当前配置

### Q: 如何修改标记？
A: 打开设置界面（`/mak`），在标记配置区域选择对应职责的标记即可。

### Q: 可以为DPS自动标记吗？
A: 可以，在设置界面中为DPS职责选择相应的标记即可。

### Q: 与其他插件冲突吗？
A: AutoMark 使用标准的WoW API，与大多数插件兼容。如有冲突，请检查插件加载顺序。
